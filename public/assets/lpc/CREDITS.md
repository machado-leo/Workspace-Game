# Creditos dos sprites (LPC - Liberated Pixel Cup)

Os sprites do boneco usados neste projeto (`public/assets/lpc/*.png`) vem do banco de
assets aberto **LPC (Liberated Pixel Cup)**, obtidos via o repositorio
[Universal-LPC-Spritesheet-Character-Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)
(GitHub, ramo `master`, pasta `spritesheets/`). Sao recombinados e recoloridos em
tempo real pelo `public/js/character.js` deste projeto — nenhuma imagem e usada "como
veio", exceto no sentido de layers combinaveis (como o proprio gerador LPC faz).

Cada arquivo listado abaixo pode ser usado sob qualquer uma das licencas indicadas
(escolha do usuario, conforme os termos do OpenGameArt.org):
